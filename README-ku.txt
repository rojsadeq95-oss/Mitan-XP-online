MitanXP Online Starter — ڕێنمایی کوردی

1. ZIP ـەکە Extract All بکە.
2. فۆڵدەری MitanXP-Online-Starter بکەرەوە.
3. دوو کلیک لە index.html بکە بۆ کردنەوەی لە Chrome.

ئەم وەشانە دیزاین، مۆدی پرسیاری نموونەیی، تایمەر، ناوی یاریزان، XP و room-code demo هەیە.

گرنگ: یاریی ئۆنلاین لە نێوان ئامێرە جیاوازەکاندا هێشتا چالاک نییە. Room code و leaderboard دیمۆی ناوخۆیین. بۆ online multiplayer ڕاستەقینە پێویستە سێرڤەر، داتابەیس، هەژمار و hosting ڕێک بخرێن. ئەوە هەنگاوی دواترە.
